# Triage labels

Use one category and one state for a triaged issue. Confirm the transition before applying it when states conflict.

| Kind | Skill role | GitHub label | Meaning |
| --- | --- | --- | --- |
| Category | `bug` | `bug` | Existing behavior is broken |
| Category | `enhancement` | `enhancement` | New or improved behavior |
| State | `needs-triage` | `needs-triage` | Maintainer needs to evaluate |
| State | `needs-info` | `needs-info` | More evidence or a decision is needed |
| State | `ready-for-agent` | `ready-for-agent` | A scoped brief and acceptance checks are available |
| State | `ready-for-human` | `ready-for-human` | Needs a person to act or make a decision |
| State | `wontfix` | `wontfix` | Closed with rationale |

The repository already has `bug`, `enhancement`, and `wontfix`. Check GitHub before using the other state labels. Create missing labels when the maintainer authorizes tracker setup.
